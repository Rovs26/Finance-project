# Decision Log

## Initial Decisions

- Focus first on Philippines inflation and policy rate analysis.
- Use a notebook-first workflow so the data and modeling process is easy to audit.
- Build the dashboard only after clean outputs exist.
- Keep Phase 1 data collection simple and transparent.

## Phase 1 Source Decisions

- Use BSP and PSA as primary Philippines macro references because they are official domestic sources.
- Use BSP historical inflation and peso-dollar Excel files as direct raw downloads for the initial collection workflow.
- Use World Bank annual indicators as backup and cross-country comparable macro context.
- Keep the MVP inflation-first before expanding to a broader nowcasting target.
- Defer automated parsing of BSP key rates, BSP prices, and PSA CPI pages until source layouts are reviewed.
