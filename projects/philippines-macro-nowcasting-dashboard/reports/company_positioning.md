# Company Positioning

Portfolio project: Philippines Macro Nowcasting and Policy Dashboard
Company-specific application angles and tailored resume bullets.

---

## BSP (Bangko Sentral ng Pilipinas)

**Why this project is relevant:**
BSP runs an explicit inflation targeting framework with a 3.0% +/-1.0pp band for 2025-2028. This project is built directly around that framework — the forecast outputs are classified relative to the band, and the policy interpretation mirrors the analytical framing a BSP research team would use. The data pipeline uses BSP's own historical Excel files as the primary source.

**Best application angle:**
Frame as a demonstration of quantitative macro research methodology: data sourcing from official BSP files, reproducible time-series analysis, transparent model limitations, and policy-relevant interpretation structured like an institutional research note.

**Tailored resume bullet:**
Built a reproducible Philippines inflation nowcasting pipeline using BSP historical data (1958-2026), evaluated three baseline forecasting models against a chronological holdout, and produced structured policy interpretation relative to the BSP 2025-2028 inflation target — demonstrating quantitative macro research methodology and BSP policy framework understanding.
