# AI Financial Research Agent

AI research workflow prototype that ingests local finance documents, chunks text, retrieves relevant evidence with TF-IDF, and prepares traceable research outputs.

**Disclaimer:** Phase 0 uses synthetic sample documents created for a portfolio prototype. They are not real company reports, investment research, or policy documents.

## Business Problem

Finance and research teams often need to review many documents and trace conclusions back to source evidence. Before using LLMs or paid APIs, a useful research workflow needs reliable ingestion, chunking, retrieval, and evidence tables.

## How to Run Phase 0

```bash
cd projects/ai-financial-research-agent
pip install -r requirements.txt
python3 -m jupyter nbconvert --to notebook --execute notebooks/01_document_ingestion_and_retrieval.ipynb --output 01_document_ingestion_and_retrieval_executed.ipynb
```

- TF-IDF retrieval only.
- No embeddings yet.
- No OpenAI API or LLM generation yet.
- No final research memo generation yet.
- No production PDF or table parser yet.
