# Project Brief

## Purpose

Build a finance research workflow that ingests documents, chunks text, retrieves relevant evidence, and prepares traceable outputs for later memo generation.

## Target Roles

- Finance analytics analyst
- Research analyst
- Risk analytics analyst
- AI workflow analyst
- Fintech analytics analyst
- Data analyst

## Target Companies

GCash, Maya, ING Hubs Philippines, PwC Philippines, KPMG Philippines, JPMorgan Chase, MSCI, UnionBank, BPI, and startups.

## MVP Scope

- Local sample finance documents
- Text ingestion
- Corpus metadata
- Text cleaning and chunking
- TF-IDF retrieval
- Evidence table outputs
- Starter figures

## Non-MVP Scope

- Paid APIs
- OpenAI API calls
- Embeddings
- Final memo generation
- Production PDF parsing
- Dashboard

## Expected Outputs

- Corpus metadata CSV
- Document chunk table
- Sample retrieval results
- Evidence table
- Retrieval and corpus figures
